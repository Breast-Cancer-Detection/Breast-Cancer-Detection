How model will interact with FastAPI:

Save ONLY the state_dict like
         torch.save(model.state_dict(), "models/breast_cancer_weights.pth")

To run inference on your FastAPI server, the server must:

Import or define the exact model architecture class (e.g., UNet or ResNet50).

Instantiate the empty architecture on CPU/GPU.

Load the saved weights into that architecture via .load_state_dict().
